## ✨ Имкониятлар

Зикрни юборгандан кейин ҳар бир фазани алоҳида ҳисоблаш ва тугаллаш имконияти.

### 📿 Зикрлар
- Дунёдаги машҳур зикрлар (субҳаналлоҳ, алҳамдулиллоҳ, Аллоҳу акбар ва бошқалар)
- Нотўғри равишда ҳисобланган исмларни тузатиш
- Кунлик зикрни пуштиқлаштириш

### 📈 Статистика
- Кундалик, ҳафталик ва умумий фазелар сони

## 🇬🇧 English

# Zikr — Dhikr Counter

A lightweight app for daily dhikr (remembrance), with a counter for each phrase and progress tracking.

</div>

### Features
- Common daily dhikr phrases (SubhanAllah, Alhamdulillah, Allahu Akbar and more) with counting
- Daily progress tracking and statistics

### Usage
```bash
git clone https://github.com/abuyahyo/zikr.git
cd zikr
# open index.html in a browser
```
